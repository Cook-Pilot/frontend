# 조리 세션 저장·복원 명세서 (feat/session-restore)

## 1. 문서 목적

이 문서는 `feat/session-restore` 브랜치에서 진행한 조리 세션 저장·복원(이어서 조리하기) 작업의 배경, 검토한 대안, 최종 결정과 구현 내용을 정의한다.

## 2. 문제 상황

MVP 조리 화면(`CookSessionScreen`)은 진행 상태(현재 단계 `int step`, 타이머)를 위젯 State에만 들고 있었다. 조리 중 앱이 종료되면(전화, 스와이프, OS 메모리 회수) 진행 상황과 남은 타이머가 전부 사라져 처음부터 다시 시작해야 했다. 화면의 "자동 저장됨" 라벨은 실제로 아무것도 저장하지 않았다.

## 3. 검토한 대안

| 안 | 내용 | 결과 |
| --- | --- | --- |
| 엔진 화면 통합 | MVP 화면을 실제 세션 엔진(`CookingSessionController` + `CookingScreen`)으로 교체하고 컨트롤러에 복원 진입점 추가 | 구현 후 실기기 확인 결과 조리 화면이 확정된 "따뜻한 키친" 디자인이 아닌 옛 파란 팔레트(DESIGN.md)의 다른 레이아웃으로 바뀌는 문제로 폐기 |
| **기존 화면 유지 + 저장만 추가 (채택)** | 확정된 디자인의 MVP 화면은 그대로 두고, 진행 스냅샷 저장·복원만 붙인다 | 디자인 변경 없음. 엔진 통합은 AI 대화가 실제로 붙는 PR에서 다시 진행 |

## 4. 최종 결정: 진행 상황 스냅샷만 로컬에 저장

| 항목 | 내용 |
| --- | --- |
| 저장 대상 | `PersistedCookingSession` — 레시피 제목, 인분, 현재 단계, 세션 상태, 타이머(원래·유효·남은 시간, 상태), 저장 시각 |
| 저장소 | `shared_preferences` 단일 키 (`cookpilot.active_cooking_session.v1`), 세션 하나만 보관 |
| 저장 주체 | `CookSessionScreen`이 진입·단계 전환·타이머 상태 변화 시점에 저장. 단계·타이머 상태·연장 값이 바뀌었을 때만 실제로 쓴다 |
| 타이머 저장 방식 | 매 틱(250ms) 저장하지 않는다. 남은 시간 + 저장 시각(벽시계)만 기록하고, 복원 시 흐른 시간을 차감해 재계산한다(`timerSnapshotAt`). 앱이 꺼져 있던 시간까지 반영된다 |
| 삭제 시점 | 조리 완료 시, 복원 불가 저장본(레시피 없음·손상 JSON) 발견 시. X로 화면을 나가는 건 "이탈"이므로 저장본을 유지한다 |

### 복원 흐름

1. 홈(`HomeScreen`)이 진입 시 저장 세션을 로드하고, 복원 가능하면 "이어서 조리하기 · N/M단계" 배너를 띄운다.
2. 배너 탭 → `CookSessionScreen`에 저장 세션(`restoredSession`)을 전달 → 해당 단계에서 시작하고 타이머를 `LocalTimerController.restore()`로 되살린다.
3. 손상된 저장값(범위 밖 단계, 음수 시간 등)은 화면과 타이머가 각각 범위 안으로 보정한다.
4. 복원된 타이머가 실행 중이면 알림 초기화 후 종료 알림을 다시 예약한다.

## 5. 범위에서 제외한 것

- **세션 엔진(`CookingSessionController` + `CookingScreen`) 통합** — 엔진 조리 화면은 옛 파란 팔레트 기반의 다른 레이아웃이라, 통합하면 확정된 디자인이 깨진다. AI 대화가 실제 백엔드로 붙는 PR에서 디자인 이관과 함께 진행한다.
- **AI 대화(질문·답변) 기록 저장** — 복원에 필수가 아니고, 고정 스냅샷이 아닌 append 로그라 저장 성격이 다르다. 엔진 통합과 같은 시점에 붙인다.
- **녹음(오디오) 저장** — 파일 시스템·용량·권한 문제가 별개라 후속 작업으로 미룬다.

## 6. 검증

- `cooking_session_store_test.dart` — 저장/로드 왕복, 손상 JSON 정리, 실행 중 타이머의 경과 시간 차감 재계산.
- `cooking_session_restore_test.dart` — 저장 단계에서 화면 시작, 범위 밖 단계 보정, 일시정지 타이머 남은 시간 복원, 진입·단계 전환 시 저장, 조리 완료 시 저장본 정리.

## 7. 이후 작업에서 지킬 것

- 저장 스키마를 바꿀 때는 키 버전(`...v1`)을 올리고 구버전은 삭제로 처리한다 (마이그레이션 대신).
- `shared_preferences`는 큰 데이터용이 아니다. 대화 기록을 저장하게 되면 최근 N개 캡을 처음부터 넣는다.
- 진행 스냅샷은 덮어쓰기 1건을 유지한다. 여러 세션 동시 보관이 필요해지면 저장소 선택부터 다시 검토한다.
- 엔진 화면을 MVP 플로우에 들일 때는 먼저 `CookPilotColors`/DESIGN.md를 "따뜻한 키친" 팔레트로 이관하고 색상 스펙 테스트를 함께 갱신한다.
