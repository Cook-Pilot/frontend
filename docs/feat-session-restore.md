# 조리 세션 저장·복원 명세서 (feat/session-restore)

## 1. 문서 목적

이 문서는 `feat/session-restore` 브랜치에서 진행한 조리 세션 저장·복원(이어서 조리하기) 작업의 배경, 설계 결정, 구현 내용을 정의한다.

## 2. 문제 상황

기존 MVP 조리 화면(`CookSessionScreen`)은 진행 상태를 위젯 메모리에만 들고 있었다.

1. **진행 상황 유실** — 현재 단계(`int step`)와 타이머가 위젯 State의 지역 변수라, 조리 중 앱이 종료되면(전화, 스와이프, OS 메모리 회수) 진행 상황과 남은 타이머가 전부 사라져 처음부터 다시 시작해야 했다. 화면의 "자동 저장됨" 라벨은 실제로 아무것도 저장하지 않았다.
2. **세션 엔진 이중 구현** — 프로젝트에는 이미 실제 세션 엔진(`CookingSessionController` + `CookingScreen`, 음성 명령·명령 기록·알람·세션 상태 포함)이 있는데, MVP 화면은 이를 쓰지 않고 자체 단계 변수 + 자체 타이머 UI로 비슷한 화면을 따로 구현하고 있었다. 저장/복원을 넣으려면 단일 진실 공급원이 필요했다.

## 3. 최종 결정

### 3.1 MVP 조리 화면을 실제 세션 엔진으로 통합

- `CookSessionScreen`은 자체 UI를 버리고 `CookingSessionController` + `CookingScreen`을 호스트한다.
- mock `Recipe`는 `recipe_cooking_steps.dart`의 `cookingStepsFromRecipe()`가 엔진 도메인 모델(`CookingStep`)로 변환한다. 이후 실제 백엔드가 붙으면 이 변환 함수만 교체하면 된다.

### 3.2 진행 상황 스냅샷만 로컬에 저장

| 항목 | 내용 |
| --- | --- |
| 저장 대상 | `PersistedCookingSession` — 레시피 제목, 인분, 현재 단계, 세션 상태, 타이머(원래·유효·남은 시간, 상태), 저장 시각 |
| 저장소 | `shared_preferences` 단일 키 (`cookpilot.active_cooking_session.v1`), 세션 하나만 보관 |
| 저장 주체 | `CookSessionScreen`이 컨트롤러에 리스너를 붙여, 단계·세션 상태·타이머 상태·연장 등 의미 있는 변화가 있을 때만 저장 |
| 타이머 저장 방식 | 매 틱(250ms) 저장하지 않는다. 남은 시간 + 저장 시각(벽시계)만 기록하고, 복원 시 흐른 시간을 차감해 재계산한다. 앱이 꺼져 있던 시간까지 반영된다 |
| 삭제 시점 | 조리 완료/중단 시, 복원 불가 저장본(레시피 없음·손상 JSON) 발견 시 |

### 3.3 복원 흐름

1. 홈(`HomeScreen`)이 진입 시 저장 세션을 로드하고, 복원 가능하면 "이어서 조리하기 · N/M단계" 배너를 띄운다.
2. 배너 탭 → `CookSessionScreen`에 저장 세션을 전달 → 컨트롤러가 `initialStepIndex`, `initialTimerSnapshot`으로 해당 단계에서 시작한다.
3. 손상된 저장값(범위 밖 단계 등)은 컨트롤러 생성 시 범위 안으로 보정한다.

## 4. 범위에서 제외한 것

- **AI 대화(질문·답변) 기록 저장** — 복원에 필수가 아니고, 저장 성격이 고정 스냅샷이 아닌 append 로그라 범위가 다르다. 현재 AI 어드바이스가 데모 포트(`DemoExceptionAdvicePort`)라 실제 백엔드가 붙으면 데이터 형태가 바뀔 가능성이 높아 다음 PR로 분리한다.
- **녹음(오디오) 저장** — 파일 시스템·용량·권한 문제가 별개라 텍스트 기록과 함께 후속 작업으로 미룬다.

## 5. 검증

- `cooking_session_store_test.dart` — 저장/로드 왕복, 손상 JSON 정리, 실행 중 타이머의 경과 시간 차감 재계산.
- `cooking_session_restore_test.dart` — 저장 단계에서 세션 시작, 범위 밖 단계 보정, 일시정지 타이머 복원 시 세션 상태 paused 반영.

## 6. 이후 작업에서 지킬 것

- 저장 스키마를 바꿀 때는 키 버전(`...v1`)을 올리고 구버전은 삭제로 처리한다 (마이그레이션 대신).
- `shared_preferences`는 큰 데이터용이 아니다. 대화 기록을 저장하게 되면 최근 N개 캡을 처음부터 넣는다.
- 진행 스냅샷은 덮어쓰기 1건을 유지한다. 여러 세션 동시 보관이 필요해지면 저장소 선택부터 다시 검토한다.
