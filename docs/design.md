# CookPilot 디자인 시스템 — design.md

> v2 · 2026-07-22 확정. 아래 결정은 제품 오너와 합의된 것이므로 임의 변경하지 않는다.
>
> 1. **무드**: 미니멀 도구 — 장식 없음, 정밀한 여백. 단 v2부터 색은 과감하게: 절제는 형태·모션이 담당하고, 색은 담당하지 않는다.
> 2. **조리 중 화면**: 블루 계열 다크 "조종 모드". 탐색은 라이트.
> 3. **컬러**: v1 포슬린+놋쇠 → **v2 코발트 & 불꽃**으로 교체 (v1 시안 리뷰 결과 "너무 심플" 피드백 반영). 코발트는 액센트가 아니라 면(面)으로 크게 쓴다.
> 4. **카피 톤**: 차분한 부기장. 존댓말, 짧고 정확, 숫자 먼저.
> 5. **시그니처**: ① 초대형 tabular 숫자 타이포 ② **그림자 커튼** — 조리 중 스텝 사진 풀블리드 위 다크 스크림, 폰 위로 손 그림자를 드리우면(조도 센서) 스크림이 걷혀 사진이 선명해진다. 터치 없는 조작.
> 6. **v3 보강** (시안 v2 리뷰 "차가움·밋밋함·템플릿감" 피드백): 식욕은 웜 그레이딩 실사진이 담당, 빛(글로우·그레인·앰비언트 섀도)을 재질로 사용.

## 1. 디자인 원칙

1. **도구는 조용하고, 색은 말한다.** 형태는 미니멀(플랫 면, 헤어라인, 3개 라운드 값)을 유지하되, 코발트를 헤더·CTA·활성 상태의 큰 면으로 쓴다. 장식용 아이콘 금지. 그라데이션·그림자는 §2.4의 빛 레이어 규격 안에서만.
1-1. **식욕은 사진이 담당한다.** UI 컬러는 구조(코발트)와 열(불꽃)만 말하고, 맛있어 보이는 일은 웜 그레이딩된 음식 사진에 맡긴다. 사진 없는 음식 카드 금지 — 플레이스홀더라도 웜 톤.
2. **숫자가 얼굴이다.** 시간·인분·단계 등 모든 수치는 instrument 서체로, 주변 텍스트보다 한 단계 이상 크게.
3. **파일럿의 두 세계.** 탐색(아이스 라이트 + 코발트 면)과 조리(코발트 언더톤 다크)는 명확히 다른 공간이지만 같은 블루 혈통. 불꽃 코럴은 양쪽에서 "뜨거운 것"(타이머, 열, 라이브 상태)만 가리킨다.
4. **2미터 가독성.** 조리 중 핵심 정보(타이머, 현재 지시)는 조리대에 폰을 두고 두 걸음 떨어져도 읽혀야 한다.
5. **부기장은 재촉하지 않는다.** 명령이 아니라 보고와 제안.

## 2. 컬러 토큰 — 코발트 & 불꽃

### 2.1 라이트 — "아이스" (탐색 모드: 인증, 홈, 검색, 상세, 조리 설정, 리뷰, 메모리)

| 토큰 | 값 | 용도 |

| `surface.bg` | `#EEF2FB` | 화면 배경. 얼음빛 블루 틴트 |
| `surface.card` | `#FFFFFF` | 카드, 시트 |
| `surface.sunken` | `#E2E8F5` | 입력 필드, 비활성 영역 |
| `ink.primary` | `#101827` | 본문, 제목 |
| `ink.muted` | `#4E5A70` | 보조 텍스트 |

| `line.default` | `#D8DFEC` | 헤어라인 디바이더 |
| `cobalt.primary` | `#2447D9` | **면으로 크게**: 홈 헤더 밴드, 주 CTA, 활성 탭, 선택 칩, 눈썹 라벨 |
| `cobalt.deep` | `#1B36A8` | pressed/hover |
| `cobalt.wash` | `#D6DFF8` | 선택 배경, 하이라이트, 진행 트랙 |

| `flame.text` | `#C93415` | 라이트 배경 위 불꽃 텍스트·아이콘 (대비 확보용) |

- 라이트 주 CTA = **코발트 필 + 백색 텍스트**.
- 홈 상단은 코발트 면 헤더 밴드 + 백색 타이포 — 앱의 첫인상이 코발트다.
- 불꽃은 라이트에서 "열·라이브"에만: 조리 중 배지, 센불 표시, 진행 중 타이머 미니 표시.

### 2.2 다크 — "심야 조종석" (조리 모드: 조리 시작 ~ 조리 완료)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `cockpit.bg` | `#0B1226` | 화면 배경. 코발트 언더톤 블루 블랙 |
| `cockpit.surface` | `#141E3A` | 패널, 카드 |
| `cockpit.raised` | `#1B2748` | 액티브 패널, 바텀시트 |
| `cockpit.ink` | `#EDF1FB` | 본문 |
| `cockpit.muted` | `#8C97B5` | 보조 텍스트 |
| `cockpit.line` | `#26325A` | 디바이더 |
| `flame.bright` | `#FF6B4A` | **다크의 주인공**: 타이머 활성, 주 CTA, 현재 단계 번호, 진행 라인 |
| `flame.dim` | `#9E4530` | 불꽃 비활성/완료 상태 |
| `cobalt.glow` | `#7C97F5` | 다크에서 정보성 보조 (링크, 보조 진행, 음성 인디케이터) |

다크에서 타이머·주 CTA는 불꽃 코럴 — 가스불 위의 조종석. 정보성 요소는 cobalt.glow로 온도를 구분한다: **불꽃 = 열/행동, 코발트 = 정보/구조.**

### 2.3 시맨틱 (양 모드 공통, 모드별 변형)

| 토큰 | 라이트 | 다크 | 용도 |
| --- | --- | --- | --- |
| `semantic.error` | `#B3261E` | `#E5604F` | 실패, 삭제. 불꽃과 구분: 에러는 어두운 적색, 불꽃은 주황 코럴 |
| `semantic.success` | `#1E7A43` | `#4C9E6A` | 저장 완료, 단계 완료 체크 |
| `semantic.warning` | `#8A5A00` | `#D99A3D` | 주의 (알레르기 재료 등. 열 관련 주의는 불꽃 사용) |

규칙: 위 토큰 외 색 추가 금지. 한 화면에서 불꽃은 최대 2곳 — 코발트는 면이므로 개수 제한 없음, 대신 층위(헤더/CTA/활성)에만.

### 2.4 포토 & 빛 레이어 (v3 신설 — "밋밋함" 대응)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `photo.grading` | 색온도 +300K, 채도 +8% 가이드 | 모든 음식 사진 웜 그레이딩. 차가운 사진 게재 금지 |
| `scrim.cook` | `rgba(11,18,38, 0.55 → 0.94)` 수직 그라데이션 | 조리 중 스텝 사진 위 스크림. 하단으로 갈수록 진하게 — 타이머·컨트롤 가독성 확보 |
| `ember.glow` | `flame.bright` 18% 라디얼, 지름 ≈ 타이머 폭 1.6배 | 조리 중 타이머 뒤 은은한 불빛. 유일한 발광 요소 |
| `grain` | 모노 노이즈 4% 오버레이 | 코발트 면·조종석 배경 질감. 라이트 백색 면엔 미적용 |
| `shadow.ambient` | `0 8px 24px rgba(16,24,39,0.10)` | 라이트 카드 1티어만 허용. 그 외 그림자 금지 유지 |

### 2.5 그림자 커튼 (시그니처 인터랙션)

- 조리 중 기본 상태: 스텝 사진 풀블리드 + `scrim.cook` + 타이머 오버레이 (96pt 유지).
- **폰 위로 손 그림자를 드리우면** 조도 센서가 급감을 감지 → 스크림이 `opacity 0.12`로 걷히고 사진이 선명해진다. 3초 후 자동 복귀. 손 씻을 필요 없는 조작.
- 감지 규격: 조도 급감(200ms 내 60% 이상 하락) 후 복귀 시 트리거. 주방 소등과 구분 — 지속 저조도는 무시.
- 플랫폼: Android `TYPE_LIGHT` 센서. iOS는 공개 조도 API 없음 → 화면 아무 곳 길게 터치로 동일 동작 (양 플랫폼 공통 폴백이기도 함).
- 스크림 전환 200ms ease. `disableAnimations` 시 즉시 컷.

## 4. 레이아웃 · 스페이싱 · 형태

- **그리드**: 4pt. 허용 스페이싱 스텝: 4, 8, 12, 16, 20, 24, 32, 48.
- **화면 좌우 패딩**: 20. 섹션 간격: 32. 카드 내부 패딩: 16.
- **라운드**: 컨트롤(버튼, 입력, 칩) 8 / 카드 12 / 바텀시트 상단 20. 그 외 값 금지.
- **엘리베이션**: 그림자 금지. 라이트는 백색 면 + 헤어라인, 코발트 면 위 카드는 오버랩(음수 마진)으로 층위 표현. 다크는 면 밝기 차로만.
- **디바이더**: 1px 헤어라인. 섹션 구분에만.

## 5. 컴포넌트

### 버튼
- **Primary**: 라이트 = 코발트 필(`cobalt.primary`) + 백색 텍스트 / 다크 = 불꽃 필(`flame.bright`) + `#0B1226` 텍스트. 높이 52, 라운드 8, `body.strong`. pressed = `cobalt.deep` / `flame.dim`.
- **Secondary**: 투명 배경 + 1px 라인 + 잉크 텍스트.
- **Text 버튼**: 라이트 `cobalt.primary` / 다크 `cobalt.glow`.
- 레이블은 동사로: "조리 시작", "다음 단계", "변경사항 저장". "확인"·"제출" 금지.

### 카드
- 백색 면, 라운드 12, 그림자 없음. 코발트 헤더 밴드 아래 첫 카드는 밴드에 걸치게 오버랩.
- 수치 메타는 `instrument.label` 스타일.

### 입력 필드
- `surface.sunken` 채움, 라인 없음, 포커스 시 1.5px `cobalt.primary` 라인. 높이 52.

### 타이머 (조리 중 핵심)
- `instrument.hero` 숫자. 실행 중 `flame.bright`, 일시정지 `cockpit.muted`, 완료 시 `semantic.success` 1회 전환.
- 뒤에 `ember.glow`, 아래에 2px 불꽃 진행 라인이 좌→우로 줄어드는 형태. 원형 링 금지 — 계기판은 직선.
- 배경은 스텝 사진 풀블리드 + `scrim.cook` (§2.5). 사진 없는 스텝은 `cockpit.bg` 단색.

### 하단 탭바 (홈/검색/메모리)
- 라이트 전용. 백색 면 + 상단 헤어라인. 활성 = `cobalt.primary` 아이콘+라벨, 비활성 = `ink.faint`.

### 단계 표시
- `STEP 3/7` — instrument.label. 현재 단계 번호만 `flame.bright`(다크) / `cobalt.primary`(라이트 프리뷰).

## 7. 카피 가이드 — 차분한 부기장

- **존댓말, 한 문장, 숫자 먼저.** "3분 후 두부를 뒤집으세요."
- **보고하고 제안한다.** "센불이 3분째입니다. 중불로 낮추는 걸 추천해요."
- **버튼은 결과를 말한다.** "조리 시작" → 토스트 "조리를 시작합니다". 같은 동작 같은 어휘.
- **에러는 원인 + 다음 행동.** "네트워크에 연결할 수 없습니다. 저장한 내용은 유지됩니다 — 다시 시도하세요."
- **빈 화면은 초대.** "아직 저장된 레시피가 없습니다. 첫 조리를 마치면 여기에 쌓입니다."
- 느낌표, 이모지, "AI가~" 자기 지칭 금지.

## 8. 모션

- **조리 진입 전환**: 유일한 큰 모션. 400ms, easeOutCubic.
- 타이머 초 전환: 크로스페이드 없음 — 고정폭 그냥 갱신. 떨림 없는 것이 계기판답다.
- 화면 전환 플랫폼 기본, 카드 히어로 애니메이션 금지.
- `MediaQuery.disableAnimations` 존중 — 전환 의식은 즉시 컷 대체.
