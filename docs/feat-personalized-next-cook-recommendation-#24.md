# F-11 조리 전 개인화 추천

## 현재 AI 구현 수준

현재 단계는 별도 AI 모델 학습이 아니라 백엔드의 추천 규칙 엔진과 Gemini 설명
생성, 추천 fallback을 연결한 AI 파이프라인을 사용하는 단계다. 베타에서는
Gemini Developer API 무료 티어를 전제로 하며, 프론트는 API 키나 모델 호출을
직접 다루지 않고 백엔드가 반환한 추천 결과만 표시한다.

## 목표

과거의 만족도 높은 조리 기록에서 반복된 재료 양 변경을 조리 전 설정 화면에서
보여준다. 추천은 자동 적용하지 않으며 사용자가 수락하거나 수정한 경우에만 이번
조리의 실행 스냅샷을 변경한다.

개인 레시피 버전 생성은 F-10의 조리 완료 흐름이 담당한다. F-11 화면에서 추천을
적용하는 것만으로 원본 레시피나 저장된 개인 버전이 변경되지는 않는다.

## 화면 흐름

1. 조리 설정 화면 진입 후 추천 API를 별도로 호출한다.
2. 개인 버전 선택 영역 아래에 `내 기록에서 찾은 추천`을 표시한다.
3. 추천별 원본 양, 추천 양, 변경률, 설명, 근거 횟수를 보여준다.
4. 사용자는 `이번 조리에 적용`, `수정`, `사용 안 함` 중 하나를 고른다.
5. 적용·수정한 양은 현재 인분에 맞게 환산되어 재료 설정에 반영된다.
6. 최종 조리 시작 시 기존 F-02 실행 스냅샷에 함께 고정된다.

추천을 적용한 뒤 기본/개인 버전을 다시 선택해도 같은 원본 재료가 그대로 유지되면
선택한 추천량을 현재 인분에 맞게 다시 반영한다. 개인 버전에서 해당 재료가 다른
재료로 대체되어 있으면 추천을 적용하지 않는다. 이후 사용자가 재료 수정 화면에서
직접 양·대체·생략을 선택하면 직접 설정을 우선한다.

## 실패 처리와 추천 fallback

- 추천 조회 실패: 추천 없이 기본 설정으로 계속 조리할 수 있다.
- 추천 근거 부족: `아직 확실한 추천이 없어요`를 표시한다.
- 추천 피드백 저장 실패: 현재 재료 설정은 유지하고 저장 실패만 안내한다.
- `explanationSource=FALLBACK`: 서버가 생성한 **추천 fallback** 설명을 그대로
  보여준다. 프론트에서 별도의 문구를 다시 계산하지 않는다.

## API

- `GET /api/v1/recipes/{recipeId}/next-cook-recommendations`
- `PUT /api/v1/recipes/{recipeId}/recommendation-feedback/{recommendationId}`

모든 요청은 현재 베타 사용자 헤더를 사용한다. 응답의 레시피 ID, 추천 목록,
근거 항목 타입을 검증하며 잘못된 응답은 추천 기능만 실패한 것으로 처리한다.

## 제외 범위

- 추천 자동 적용
- F-11 화면에서 개인 레시피 버전 생성
- 재료 대체 추천
- 조리 단계·타이머 추천
- 다른 요리 추천 피드
- 조리 중 실시간 AI 대화
