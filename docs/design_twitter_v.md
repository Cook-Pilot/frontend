# CookPilot 디자인 시스템 — design_twitter_v.md (X 스타일)

> 2026-07-22 확정. `design.md`(v2~v3 코발트 계열)를 대체하는 신규 방향. 아래 결정은 제품 오너와 합의됨.
>
> 1. **범위**: X(트위터) 스타일은 **비주얼 문법까지만** — 화이트/헤어라인/필/밀도/미니바. 홈 타임라인 구조는 시안 검토 후 기각(2026-07-22): 레시피 앱엔 흘려보낼 무한 콘텐츠가 없어 피드가 억지. 시간순이 자연스러운 **메모리만 타임라인 문법 유지**. 소셜 기능은 MVP 제외.
> 2. **모드**: 화이트 베이스 (X 라이트 모드 문법: 퓨어 화이트 + 블랙 잉크 + 헤어라인). 다크 미지원.
> 3. **액센트**: X 블루 자리를 **오렌지 `#FF8A3D`**가 차지. 음식 앱 정체성 유지 + X 모방감 회피.
> 4. **승계 자산**: ① 그림자 커튼(조도 센서) ② 초대형 tabular 숫자 타이포 ③ 버전 슬라이더. 하늘 블루 "부기장" 레이어는 폐기 — AI 정보도 일반 잉크/오렌지 체계로 편입.

---

## 1. 원칙 — X 문법의 번역

1. **피드가 곧 홈이다.** 배너·섹션·히어로 없음. 카드가 세로로 흐르고, 헤어라인 하나로만 구분된다. 콘텐츠(레시피·기록·제안)가 전부이고 크롬은 최소.
2. **엣지-투-엣지 + 헤어라인.** 카드에 테두리·그림자·배경색 없음. 화면 가로 전체를 쓰고 `1px` 헤어라인으로만 나눈다. 라운드는 미디어와 필 버튼에만.
3. **필(pill)이 유일한 버튼 형태.** 모든 버튼·칩·배지는 완전 라운드. X의 "Post" 버튼 문법 = 우리의 "조리 시작".
4. **숫자는 계기판.** X 문법 위에서도 시간·인분·단계는 Space Mono tabular — 유지 자산 ②.
5. **밀도는 X, 톤은 부엌.** 정보 밀도와 리듬은 X 타임라인, 카피는 존댓말·한 문장·숫자 먼저(기존 카피 가이드 승계, "부기장" 자기 지칭은 제거).

## 2. 컬러 토큰

X 라이트 모드의 쿨 그레이 스케일 + 오렌지 액센트. **대비값은 v5.1 리뷰에서 검증된 규칙 승계** — 원색은 채움/보더, 텍스트는 전용 딥 토큰.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `bg` | `#FFFFFF` | 화면 배경. 퓨어 화이트 |
| `ink` | `#0F1419` | 본문·제목 (X 잉크) |
| `ink.muted` | `#536471` | 보조 텍스트 (X 그레이) |
| `line` | `#EFF3F4` | 헤어라인 디바이더 |
| `sunken` | `#F7F9F9` | 검색바·입력 채움 |
| `sun` | `#FF8A3D` | 필 버튼 채움, 활성 인디케이터. **위 텍스트는 `ink`** (백색 금지 — 2.35:1) |
| `sun.deep` | `#E8641B` | pressed, 선택 보더 (비텍스트 3.35:1) |
| `sun.text` | `#B84A0E` | 오렌지 텍스트·아이콘 (4.9:1) |

| `semantic.error` | `#C62F21` | 실패·삭제 |

- 사진 = 유일한 진한 컬러 면. 웜 그레이딩 규칙 유지.
- 카카오 로그인 버튼은 브랜드 강제값 `#FEE500` + `#191919` 텍스트.

| 역할 | 서체 | 스케일 |
| --- | --- | --- |
| 숫자·타이머 | **Space Mono** (tabular) | 타이머 96 / 인분 40 / 메타 숫자 인라인 |

- 라운드: 미디어 16 / 필 999 / 바텀시트 16. 그 외 금지.

## 4. 레이아웃 · 컴포넌트

### 홈 — "오늘" 화면 (타임라인 아님)
- 목적형 2섹션, 헤어라인으로 구분: ① **오늘 이거 어때요** — 추천 1개, 라운드 16 미디어 + 액션 로우 ② **다시 만들 때 됐어요** — 내 기록 기반 리마인드 1개(원형 썸네일 + "지난번: 간장 2큰술로 줄임 · 만족 5/5" 인용 + "내 기록으로 조리"). 무한 스크롤 없음, 카드 수 고정.
- 액션 로우 = X 엔게이지먼트 로우의 번역: `담기(북마크) · 버전(2) · 25분 · 조리 시작`. 아이콘 스트로크 1.5px, 터치 타깃 44px.
- AI 제안은 홈에 노출하지 않음 — 상세의 버전 슬라이더("부기장 제안")가 유일한 자리.
- 카드 탭 = 상세 진입 (커튼과 분리 — v5.1 결정 유지).

### 진행 중 조리 미니바 (전역 FAB 대체)
- 전역 "조리 시작" FAB는 **없음** — X의 compose는 무맥락 전역 액션이지만 조리 시작은 레시피 컨텍스트가 필요하다는 결정(2026-07-22). 조리 진입은 항상 카드 액션 로우·상세 CTA에서.
- 대신 **조리 세션이 진행 중일 때만** 탭바 위에 미니바 등장(미니플레이어 문법): `[28px 원형 썸네일] 레시피명 · 단계 · 화력 [타이머(mono, heat)] 이어서`. 탭하면 조리 중 화면 복귀. 세션 없으면 아무것도 없음.

### 탭바
- 홈 / 검색 / 메모리 3탭. 활성 = `sun.text` + 채워진 아이콘, 비활성 = `ink.muted` 스트로크. 인디케이터 없음(X 방식).

### 검색
- X 탐색 탭 문법: 상단 고정 라운드 필 검색바(`sunken` 채움) + "지금 많이 찾는" 리스트(트렌드 자리 — 인기 검색어 순위 `1 두부`, `2 파스타`…) + 결과는 피드 카드 재사용.

### 상세 — 버전 슬라이더 (유지 자산 ③)
- 가로 스크롤 필 세그먼트: `기본` / `내 기록 v2` / `부기장 제안`(점선). 선택 = `sun.deep` 보더 + 워시. 아래 재료·단계가 버전 따라 갱신.
- 사진은 상단 라운드 16 미디어, 커튼 대상.

### 조리 중 — 그림자 커튼 (유지 자산 ①)
- 화이트 베이스 유지: 상단 사진(라운드 0, 엣지-투-엣지) ~45% + 하단 화이트 계기판.
- `3/4 단계` 필 배지 + `중불` heat.deep 필 배지 (heat 사용 화면당 최대 2곳: 배지+타이머 규칙 유지).
- 타이머 96pt `heat`, 아래 2px 직선 진행 라인. 조작 3버튼 필, 높이 56px.
- **커튼 규격 (v5.1 확정판 승계)**: 손을 한 번 흔들면(조도 200ms 내 60% 급감→복귀) 사진이 풀스크린 6초, 재웨이브로 연장, 펼친 동안 미니 타이머 우상단 유지. 어두운 주방은 자동 비활성 + 탭 폴백. iOS는 롱프레스 폴백. wakelock 상시.

### 리뷰 · 메모리
- 리뷰: 3단 만족도 필 세그먼트 + 자동 기록 diff 리스트 + CTA "저장하고 마치기". 저장 방식 화면 없음(자동 저장).
- 메모리: 내 프로필 타임라인 문법 — 내 조리 기록이 시간순 피드로. 버전 필 배지(`v3`) + 날짜 표기.

## 6. 접근성 · 미결 사항

- 대비: 위 토큰표의 검증값 준수. 백색 on `sun` 금지. 터치 타깃 44px, 조리 중 56px.
- 모션: 커튼 200ms / 시트 300ms. `disableAnimations` 시 즉시 컷.
- **미결(제품 결정 대기, v5 리뷰에서 이월)**: ① 게스트 자동 저장 정책(인라인 로그인 배너 + 로컬 보관 권장) ② 자동 저장 오염 방지 — diff 항목별 "기억하기" 토글, 변경 0건이면 버전 미생성 ③ "부기장 제안" → 인기 버전 교체 시점(커뮤니티 데이터 임계치).
- 구현 선행: pubspec 의존성(riverpod/dio/freezed + light_sensor류 + wakelock_plus + 폰트), UI 트리 단일화(`features/mvp` 폐기), `RecipeStep` 이미지 필드, 버전별 재료/단계 데이터 모델.
